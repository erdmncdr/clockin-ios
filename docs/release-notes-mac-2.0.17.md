# Clockin 2.0.17

- Clock out from Chrome works on more sites. The extension now recognises buttons built from other page elements, and sends the command even when the site changes page right after the click.
- The Clockin extension shows the last press it noticed and when, so you can tell whether a press reached it.
- After updating, reload the Clockin extension in chrome://extensions (or restart Chrome). Your picked buttons stay.
