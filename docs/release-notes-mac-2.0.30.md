# Clockin 2.0.30

- Weeks run from Monday to Sunday. History's Week view and the weekly cells in Reports now follow the calendar week, crossing month and year boundaries, instead of slicing each month into 1–7, 8–14, 15–21 and so on.
- Entries you add by hand are marked "Manual entry" and are never merged with a timer session that started at the same moment. Entries created by older versions keep working as before.
