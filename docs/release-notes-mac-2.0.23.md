# Clockin 2.0.23

- When Clockin's menu bar icon doesn't show, Today and Settings > Menu bar have a new Test menu bar button. Clockin briefly adds two test icons and tells you what it found: the menu bar has no room left, or macOS doesn't take Clockin's icons into the menu bar at all, or only Clockin's own icon stays away (Clockin then remakes it like the test icon that worked).
- The notice no longer says the menu bar is full before anything has been tested.
- Copy details now includes the test, what macOS did with the icon after launch and before and after Reset position, other running copies of Clockin, and the copies macOS has on record.
