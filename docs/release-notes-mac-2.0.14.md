# Clockin 2.0.14

- If macOS hides Clockin because the menu bar is full, Today now says so and offers the pinned timer, so the timer never disappears without a word. Hold ⌘ and drag other icons out of the menu bar to make room for Clockin.
- The menu bar timer is shorter by default: the Turkish lira equivalent is off unless you turn it on in Settings > Menu bar, so the item fits more often.
