# iOS 0.2 (38): Weight after the strike

Repository: `erdmncdr/clockin-ios`.
Source: main at `09957483487a57e9139612241ad520d32e91e18c`.

  bells and sparkles, which sounded thin. It stays low and heavy: a
  brass-like C minor chord that opens with the blow and darkens as the light
