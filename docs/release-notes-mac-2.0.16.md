# Clockin 2.0.16

- Picking your work site's buttons in Chrome works when Clock out only appears after you clock in. Pick buttons now asks for the start button first and lets that click work on the site; once it shows its Clock out button, pick that one. Even if the site reloads the page in between, the extension picks up where it left off.
- After updating, reload the Clockin extension in chrome://extensions (or restart Chrome) and pick the buttons again.
