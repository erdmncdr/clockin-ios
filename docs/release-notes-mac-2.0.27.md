# Clockin 2.0.27

- Pulse: the button picker in Chrome accepts only real clicks, and a watcher left in an open tab stops sending presses after Remove or after you pick another site. Chrome reloads the extension from the app's copy; if Pulse still shows 1.3, open chrome://extensions and press Reload.
- Copy details in Menu bar settings no longer includes the menu bar text, which can show earnings.
- A sync error line no longer puts the record key in the system log.
