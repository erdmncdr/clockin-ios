# Clockin 2.0.26

- A timer log in Settings > General lists every clock-in, resume and clock-out with where it came from: the app, a keyboard shortcut, Pulse in Chrome, a link from another app, or another device through iCloud. Use it when the timer seems to start on its own.
- Links that open `clockin://clock-in` or `clockin://clock-out` from another app or a web page now ask before changing the timer. Pulse keeps working without a question.
- The global shortcuts can be turned off in Settings > General. ⌥⌘I is also Show Inspector in Finder and Web Inspector in Safari and Chrome; turn the shortcuts off if the timer starts when you press it there.
