# Clockin 2.0.22

- Opening Clockin straight from Downloads (or the Desktop) now always brings the "Move to Applications" question to the front, with Clockin in the Dock while it asks. Before, the question could stay hidden behind other windows or full-screen apps, and Clockin waited for it without showing its menu bar icon.
- A copy in Downloads asks every time until it is moved: "Don't ask again" is only offered for a folder you chose yourself, and an earlier "Don't ask again" no longer keeps a downloaded copy there.
- A downloaded copy is no longer mistaken for a development build when macOS keeps Downloads private, which also stopped the question from appearing.
- Copy details (Settings > Menu bar) now also says where Clockin runs from.
